DUPLIO - START HERE
===================

Duplio finds duplicate files and keeps copies of your files safe. It never deletes anything
without showing you first, and everything it moves can be put back.

You do not need to install anything except Python (free), if your computer does not have it yet.
The launcher below tells you if Python is missing and how to get it.

WINDOWS
  1. If you downloaded a ZIP file: right-click it, choose "Extract All...", and open the new folder.
  2. Double-click  Duplio.bat

MAC
  1. If you downloaded a ZIP file: double-click it to unpack it, and open the new folder.
  2. Double-click  Duplio.command
     (The first time, macOS may say it cannot be opened. Right-click the file, choose Open,
      then click Open again. You only have to do this once.)

LINUX
  1. Unpack the download and open a terminal in the new folder.
  2. Run:  ./duplio.sh
     (If it says "permission denied":  chmod +x duplio.sh   and try again.)

A window opens. Every screen shows two folders next to each other, A on the left (blue) and B on
the right (red), with the real pictures:

  Compare two folders   what is in one and not the other, and copy the difference over
  Is it backed up?      is everything in A also in B (your backup)?
  Find duplicates       identical files, side by side; clear the extra copies safely
  Keep in sync          make two folders match without destroying anything
  Import from phone     bring only the new photos from a phone or card into your library
  History & undo        put back anything Duplio changed

Looking never changes anything. Before a button changes files it shows you the whole list.

If the window does not open, this computer's Python has no "Tk" (Linux: sudo apt install python3-tk;
Windows/Mac: install Python from python.org). Duplio then opens a text screen instead:
arrow keys and Enter, ? for help, Ctrl+Q to leave.

Looking at pictures on a slow or far-away drive (a NAS, a cloud drive, a USB stick)? Duplio
fetches only the small preview built into each photo and remembers it, so browsing stays quick.
You can read how in README.md ("Pictures on slow drives").

More commands (for people who like typing):   Duplio.bat --help   /   ./duplio.sh --help
